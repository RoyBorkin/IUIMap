# מפת הקרקעית – חוף המכון הבין־אוניברסיטאי, אילת

מפה תלת־ממדית של העצמים מתחת למים בחוף המכון הבין־אוניברסיטאי (IUI), עם חתכי עומק של 3, 6 ו־9 מטר, מסלול צלילה בסגנון מפת אוצר, מפת לוויין לניווט מהיר, ושקופיות על הצוותים ועל תכנון המשימה.

האתר סטטי לגמרי (HTML, CSS, JavaScript) ואין צורך בהתקנה או בבנייה. כל הספריות (three.js ו־Leaflet) כלולות בתיקייה `vendor`.

## העלאה ל־GitHub Pages

1. צרו מאגר חדש ב־GitHub והעלו אליו את כל הקבצים שבתיקייה הזו (כולל `.nojekyll`).
2. במאגר: **Settings → Pages**.
3. תחת **Build and deployment** בחרו **Deploy from a branch**, את הענף `main` ואת התיקייה `/ (root)`, ולחצו **Save**.
4. אחרי דקה־שתיים האתר יהיה זמין בכתובת `https://<שם-המשתמש>.github.io/<שם-המאגר>/`.

## צפייה מקומית

הדפדפן לא טוען מודולים מקובץ שנפתח ישירות, לכן צריך שרת קטן:

```
python -m http.server 8000
```

ואז לפתוח `http://localhost:8000`.

## עריכת התוכן

כל התוכן נמצא בקובץ אחד: `js/data.js`.

- **נקודות** (`POINTS`): שם, נ.צ. (מעלות ודקות כמו בטבלה), עומק, מידות, קרקעית וחומר.
- **תמונות**: שימו את הקבצים בתיקייה `assets/photos` והוסיפו אותם לנקודה:
  ```js
  photos: [{ src: 'assets/photos/nursery-1.jpg', caption: 'המשתלה ממערב' }]
  ```
  כל עוד אין תמונות, מוצג שרטוט של העצם לפי המידות שנמדדו.
- **חומר**: השדה `material` ריק ברוב הנקודות, כי הוא לא נרשם בטבלה. מלאו אותו כשיש מידע.
- **שקופיות** (`DECKS`): החליפו את `[שם]` בשמות חברי הצוות וערכו את הטקסטים.
- **מצלמה בשידור חי**: מזהה הסרטון ביוטיוב נמצא ב־`LIVE_CAMERA_YOUTUBE_ID`.

## הערות על הנתונים

- לחמש נקודות אין נ.צ. בטבלה (שולחן ריק, שולחן עומק, השולחן של שחר, גליל ליד המזח, בטונדה משמאל למזח). המיקום שלהן מחושב מהאזימוט והמרחק שנרשמו, ומסומן באתר כ"משוער". בגליל ובבטונדה שליד המזח הכיוון נקבע לפי תיאור מילולי בלבד, ולכן כדאי לבדוק אותו.
- פני הקרקעית בתלת־ממד מחושבים מתוך העומקים שנמדדו בנקודות (משטח מותאם ותיקון מקומי סביב כל נקודה). זה קירוב, לא סקר באתימטרי.
- הציר האנכי מוגבה פי 3 כדי שהעומקים יהיו קריאים. אפשר לשנות ב־`SITE.verticalExaggeration`.
- תמונות הלוויין: Esri World Imagery.
